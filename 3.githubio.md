# Setting up personal website

https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

Github allows hosting a personal website as a repo. To do so, 

1. Create a new repository and name it 

    `<your-username>.github.io`

    Set the visibility to public.

2. Once created, clone to your computer add a file called `index.html`

    Add some boilerplate HTML, e.g.

    ```
    <!DOCTYPE html>
    <html lang="en">
    <head>
        <meta charset="UTF-8">
        <title>My GitHub Website</title>
    </head>
    <body>
        <h1>Hello, World!</h1>
        <p>Welcome to my brand new website hosted on GitHub Pages!</p>
    </body>
    </html>
    ```
    Commit this to your repo


3. On your github repo page, `Settings -> Code, planning, and automation -> Pages -> Build and deployment`

    Select "Deploy from a branch" and choose "main" (or whatever branch you want).


4. Allow some time between edits being pushed and github rendering the webpage. Your new website will be found at `https://<yourusername>.github.io`


There are *some* javascript plugins available to you, but the build system is fairly barebones. I would recommend finding a nice free template online and using that, but definitely test it out through github before commiting to using it since it may not work if it relies too much on external javascript dependancies. 

e.g. Templates: https://jekyllthemes.io/free
