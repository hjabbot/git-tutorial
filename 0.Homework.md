## 2. Create a github account

Github acts as cloud storage for any git repos that you create. 

It is not strictly necessary to use github for your git projects, but it is incredibly convenient for sharing code with collaborators/reviewers, as well as keeping your code up to date on whatever devices you own. 

## 3. Configure 
In order to get github to recognise your computer as you, some work is required for automated authentication.

### 3.1 SSH Keys
https://docs.github.com/en/authentication/connecting-to-github-with-ssh/generating-a-new-ssh-key-and-adding-it-to-the-ssh-agent

Github uses SSH to do authentication. Passwords are no longer supported, so unless you're running a reaaally old version, you have to set up passwordless authentication. 

Basic steps:

1. Generate new SSH key unique to your computer (you may already have one). 
    
    Doing this will produce 2 files (e.g. id_ed25519, id_ed25519.pub). The .pub file contains text that is your public key. The other file is your private key. **NEVER GIVE YOUR PRIVATE KEY TO ANYONE**

2. Add your public SSH key to your github account (Profile Icon->Settings->SSH and GPG Keys). 

    Authentication keys are fine for your use case. Signing keys are only useful for tightly controlled projects.


### 3.2 Username and Email
https://docs.github.com/en/get-started/git-basics/setting-your-username-in-git

You've linked your computer to your github account now, but now you have to link yourself to your computer (kinda weird I know). 

From a terminal

`git config --global user.name "My Name"`

`git config --global user.email "name@domain.com"`

The `--global` flag tells your config that you want to use these credentials for every project you work on from this computer. 

**P.S.** These credentials you type in are public, if you do not want to share these details, then you can change them to whatever gobbledegook you want. Emails *can* useful for getting notifications from random potential collaborators. If you want to recieve emails but not have your personal email be public, github provides an anonymised email address for you. Check this out under Profile Icon->Settings->Emails. In the first blurb of text, there is a weird looking email address you can copy (e.g. \<uid>+\<username>@users.noreply.github.com).
